    v1.6.1

    October 14, 2026

    The v1.6.1 release is a small follow-up to v1.6.0: a few polish items for the redesigned budget and Plan grid, plus fixes the team found while shipping that release. There are no breaking changes and no database migrations — upgrading is a straight image bump.

    What’s new #

    • Totals rows now highlight on hover, exactly like the rows above them — the Total row and the totals lines (Income, Expenses, Transfers outside budget, Savings, Total savings, Balance at month end) in both the Budget view and the Plan grid.
    • Folder menus can create a tag directly. Open a folder’s ⋮ menu (or the Expenses section menu) in the Budget view or the Plan grid, and New tag now sits next to New envelope and New category. The new tag is placed at the top of that folder.
    • Usage statistics moved into its own dialog. In Settings → Personal settings, under Preferences, Usage statistics is now a plain row; tapping it opens a dialog explaining what’s shared (nothing financial or personal, ever) before you decide, instead of a switch sitting directly on the page.

    Fixes #

    • The budget transactions dialog (opened from a Spent/Received/Saved cell) now shows the payee next to the category on transaction rows that have no note — before, those rows showed only the category.
    • Merging or deleting a category, tag, payee or label from the Plan grid’s row menu now refreshes the grid immediately, instead of waiting for the next manual sync.
    • Editing a Plan cell now draws a single ring around it — editing used to draw a second ring around the input inside the cell.
    • A focus outline no longer appears around the whole Plan grid after pressing Enter or Esc in a cell editor, or closing a transactions list with Esc.
