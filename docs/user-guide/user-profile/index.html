    Accessing your user profile #

    Open Settings and select the card with your name at the top of it — it is labelled Personal settings, and so is the page it opens. The page shows your personal details, preferences and security settings. To sign out, press Log out: it sits under that card on the Settings page and at the top of Personal settings.

    Updating your user profile #

    How to change your name #

    Type the new name in the “Name” field and tap outside it — the change is saved automatically.

    How to change your email #

    Choose Change email in the Security section, enter your New email and Current password, and press Send confirmation code. Econumo emails a code to the new address to confirm you own it before the change takes effect; your old address gets a notice, and every other session is signed out.

    How to change your avatar #

    Click your avatar on the profile screen to open the avatar picker. Choose a color and an icon, then press Save. Your avatar is shown to everyone you share accounts and budgets with.

    How to change your password #

    Choose Change password in the Security section. Enter your current password, then the new one twice:

    Note On a self-hosted instance with password sign-in turned off (ECONUMO_PASSWORD_LOGIN=false), neither Change password nor Set a password appears here — every sign-in goes through a linked provider instead.

    How to change your default currency #

    The Currency preference in the Preferences section sets your default currency in Econumo.

    How to change the interface language #

    The Language preference sits right below Currency. Open it and pick one of the 11 available languages — English, Deutsch, Español, Français, Italiano, Nederlands, Polski, Português, Русский, Українська, and 简体中文. The same dialog is available from the language badge on the sign-in and sign-up screens, before you have an account.

    How to switch to dark mode #

    Theme, under Language, switches Econumo between Light and Dark. System follows your device’s appearance. The theme applies only to the device you set it on.

    Usage statistics and AI features #

    The last two Preferences each open a dialog with a single switch:

    • Usage statistics → Help improve Econumo. Usage statistics show us which features are most popular and what to improve. Switching it off stops Econumo from sending in-app usage events right away, and the setting follows your account across devices.
    • AI features → Use AI features. AI helps keep your finances organized — for example with rule suggestions for imported transactions. This preference appears only when your Econumo server has AI set up, and it is on by default. Turning it off stops everything that would send your data to the AI and removes your open suggestions.

    Note Neither switch touches your budgets, transactions, or any other data in your account. Your financial data and personal information, such as your name or email, are never included in usage statistics and never sent to the AI.

    Sign-in methods #

    Security → Sign-in methods lists the external accounts you can use to sign in instead of a password — Google, Apple, or a custom OpenID Connect provider, whichever your Econumo instance enables. Each provider your instance turns on appears here with a LINK button.

    Press LINK to connect a provider: Econumo hands you off to it to confirm it’s you, then brings you back with the provider listed as linked, its button now reading UNLINK. From then on you can sign in either with your password or with that provider.

    Note Unlinking is the same button in reverse. If a linked provider is the only way into your account, Econumo won’t let you remove the last one. For a passwordless account, set a password first from Change password. On an instance with password sign-in turned off, a stored password no longer counts as a way in either, so the last remaining provider can’t be unlinked at all — the button is disabled with a note explaining why.

    Linking or unlinking a provider emails you a notice, so gaining or losing a way into your account never happens without you knowing.

    Sessions #

    Security → Sessions lists every device currently signed in to your account, with the browser and operating system it was identified as and when it was last active. Your current session is marked Current.

    Press Revoke next to a session to sign that device out, Sign out to end the session you are using right now, or Sign out other devices to end every session except the current one.

    Note If you spot a session you do not recognise, revoke it and change your password.

    App lock #

    Security → App lock asks for a PIN or a pattern whenever Econumo opens on this device — useful on a shared tablet or a phone you hand to your kids.

    1. Switch on App lock.
    2. Choose PIN (4 to 8 digits) or Pattern (connect at least 4 dots), enter it, and enter it again to confirm.
    3. Under Lock after, choose when Econumo locks once you leave it: Immediately, after 1 minute, 5 minutes or 15 minutes.

    Change PIN or pattern asks for the current one first.

    Note The lock protects Econumo on this device only, and it doesn’t encrypt the data stored on the device. If you forget the PIN or pattern, choose Forgot PIN? (or Forgot pattern?) on the lock screen and log in again.

    API tokens #

    Econumo has a REST API, and personal access tokens are how you authenticate against it — handy for scripts, home-automation dashboards, or any integration of your own. Open Security → API tokens to manage them.

    Press Create token, give it a name that will remind you what it is for (for example, “Home Assistant”), and choose when it expires: 30 days, 90 days, 365 days, a custom date, or never.

    Note A personal access token grants full access to your account over the API — treat it like a password. Create a separate token per integration so you can revoke one without breaking the others.

    The same tokens also authenticate Econumo’s built-in MCP server. Claude and Codex no longer need one — they sign in through the browser, see AI assistants (MCP) — but a token still works for any MCP client that can’t.

    Connected apps #

    Security → Connected apps shows the address of Econumo’s built-in MCP server — for Econumo, https://app.econumo.com/mcp — with a Copy button, and lists every AI assistant you have allowed to use your account, with when it was connected and when it was last used. Revoke signs an app out right away.

    To connect Claude, Claude Code or Codex step by step, see AI assistants (MCP).
