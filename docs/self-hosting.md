# Self-Hosting

**Econumo Self-Hosted** gives you full control over your financial data by
running Econumo on your own infrastructure. It is free and MIT-licensed, and it
ships as a single self-contained binary: one small Docker image, or one Linux
executable, serving both the API and the web app. It stores data in SQLite by
default, with PostgreSQL as an option.

This section covers installing, configuring and running your instance.
